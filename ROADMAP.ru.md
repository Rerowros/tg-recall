# Roadmap

[English](ROADMAP.md) | **Русский**

`v0.9.0` — текущий релиз и кандидат в 1.0. tg-recall — это локальный архив Telegram и несколько дешёвых по токенам инструментов (`search`, `read`, `stats`, `export`, `chats`, `sync`, `transcribe`) для вас и ваших AI-агентов через MCP или CLI.

## Принципы продукта

- Local-first: архив, сессия, credentials, медиа и exports остаются в выбранном приватном профиле.
- Telegram только на чтение: tg-recall никогда не отправляет, не редактирует и не помечает сообщения прочитанными.
- Явный доступ агентов: агенты ничего не видят, пока владелец не включит `ai_access`; менять конфигурацию, входить в Telegram и удалять данные они не могут.
- Дёшево для агентов: компактный текст в пределах бюджета токенов со ссылками `tg://` на исходные сообщения.
- Небольшая поверхность: рассуждения, сводки и долгосрочная память — дело вызывающего агента, а не tg-recall.

## История

- `v0.1.0`: локальный архив SQLite, авторизация Telegram, полнотекстовый поиск со ссылками, CLI и read-only MCP-сервер.
- `v0.2.0`: переименование в `tg-recall`; профили, portable-режим `--home` и медиа с адресацией по содержимому.
- `v0.5.0`: усиленная политика доступа агентов, обслуживание архива (`doctor`, `jobs`) и миграции схемы.
- `v0.6.0`: русская документация и настраиваемая локальная транскрипция.
- `v0.7.0`: релиз ядра. Удалены ответы LLM, эмбеддинги, research sessions, wiki memory, export packs, установщики harness, самообновление и sync scopes; добавлены компактные инструменты для агентов, темы форума, быстрый `sync` и автообновление для агентов.
- `v0.8.0`: большие периоды для агентов: подсчёты `stats`, выгрузка в файл через `export`, фоновый `sync`, `transcribe` для голосовых по ссылкам, синтаксис поиска и журнал `usage`. См. [журнал изменений](CHANGELOG.ru.md).
- `v0.9.0`: кандидат в 1.0: обещание [совместимости](docs/compatibility.ru.md), которое проверяют тесты контракта и обновления.

## 1.0

`v1.0.0` — это `v0.9.0` после периода реального использования без ломающих изменений, опубликованный в PyPI. С этого момента действуют правила [совместимости](docs/compatibility.ru.md): 1.x только добавляет.

## Дальше

Дальнейшая работа идёт от реального использования; опишите свой случай в issue. Сейчас в списке кандидатов:

- Публиковать каждый релиз в PyPI, а не только в GitHub Releases.
- Записать короткое демо для README.
- Держать вывод для агентов компактным по мере изменения MCP-клиентов и проверять это на реальных архивах.

Регрессии приватности, доступ агентов шире настроенного, потеря ссылок на источники и несовместимость backup блокируют релиз.
