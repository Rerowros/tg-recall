# Локальная транскрипция

[English canonical](local-transcription.md) | **Русский**

`tg-recall` хранит медиа и транскрипты в выбранном локальном профиле. Это
руководство описывает, как человек выбирает способ расшифровки и настраивает
уже установленный на компьютере движок. Оно не загружает модели или пакеты.

## Как работают способы расшифровки

`transcribe run` по умолчанию использует `sidecar`. Он читает подготовленный
человеком текстовый файл рядом с медиа: для `voice.ogg` это `voice.ogg.txt`.
Это удобно, когда текст уже подготовлен в другом месте и распознавание речи
запускать не нужно.

`telegram` просит Telegram расшифровать подходящее медиа. `local` запускает
выбранный в профиле локальный адаптер. `auto` сначала обращается к Telegram, а
локальному адаптеру передаёт только незавершённые задания или задания, готовые
к повтору. Если Telegram уже завершил задание, локальный адаптер для него не
запускается.

Локальная расшифровка запускает выбранный исполняемый файл на этом компьютере.
Напротив, `telegram` задействует Telegram. Выбирайте `local`, если после
скачивания в профиль медиа должно оставаться только на компьютере.

## Конфигурация только для человека

Менять конфигурацию профиля через `config set` может только человек. Автоматизация,
MCP и AI-агент не могут её изменять. Поддерживаются поля:

| Поле | Назначение |
| --- | --- |
| `transcription.backend` | `whisper-cli` (совместимое значение по умолчанию) или `faster-whisper-xxl`. |
| `transcription.executable` | Необязательный явный путь к исполняемому файлу; иначе нужный движок обнаруживается автоматически. |
| `transcription.model` | Имя локальной модели; обязательно для `faster-whisper-xxl`. |
| `transcription.model_dir` | Необязательная папка с локальными моделями Faster-Whisper-XXL. |
| `transcription.language` | Необязательная подсказка о языке, например `ru`. |
| `transcription.device` | Необязательный выбор устройства: `auto`, `cpu`, `cuda` или `cuda:N`, где N — номер CUDA-устройства. |
| `transcription.compute_type` | Необязательный проверяемый тип вычислений Faster-Whisper: `default`, `auto`, `int8`, `int8_float16`, `int8_float32`, `int8_bfloat16`, `int16`, `float16`, `float32` или `bfloat16`. |
| `transcription.vad_filter` | Необязательное включение обнаружения речи; не задавайте, чтобы сохранить поведение движка по умолчанию. |
| `transcription.timeout_seconds` | Положительное ограничение времени работы локального процесса. |

Настроек `extra_args`, шаблона команд и строк для оболочки нет. Каждое
поддерживаемое значение проверяется и передаётся отдельным аргументом.
`tg-recall` не скачивает модели: перед запуском Faster-Whisper-XXL требует
точную существующую папку `faster-whisper-<model>` внутри `model_dir` (либо
`_models` рядом с исполняемым файлом, заданным абсолютным путём).

Если секции `transcription` нет, сохраняется совместимое поведение
`whisper-cli`: `whisper` ищется в `PATH`, а его существующий контракт JSON-команды
остаётся без изменений.

## Предустановки Faster-Whisper-XXL

Ниже приведён только пример для RTX 4050 Laptop с 6 ГБ VRAM, а не требование к
оборудованию. Он использует уже локальную модель `large-v3-turbo` и
`int8_float16`. Если видеопамяти не хватает или этот вариант не подходит
компьютеру, используйте уже локальную модель `medium`.

### Короткие голосовые сообщения Telegram

Установите VAD в `false`: иначе очень короткие ответы могут быть удалены как
тишина.

```powershell
tg-recall config set transcription.backend faster-whisper-xxl
tg-recall config set transcription.executable "C:\Tools\faster-whisper-xxl\faster-whisper-xxl.exe"
tg-recall config set transcription.model large-v3-turbo
tg-recall config set transcription.model_dir "C:\Tools\faster-whisper-xxl\_models"
tg-recall config set transcription.language ru
tg-recall config set transcription.device cuda
tg-recall config set transcription.compute_type int8_float16
tg-recall config set transcription.vad_filter false
tg-recall config set transcription.timeout_seconds 180
```

### Длинные или шумные аудиозаписи

Сохраните остальные настройки выбранного движка и установите VAD в `true`,
чтобы пропускать длинные фрагменты без речи:

```powershell
tg-recall config set transcription.vad_filter true
```

Чтобы перейти на более лёгкую локальную модель, поменяйте только имя модели,
убедившись, что соответствующая папка уже существует:

```powershell
tg-recall config set transcription.model medium
```

Для прежнего CLI, совместимого с OpenAI, выберите `whisper-cli`; модель
Faster-Whisper-XXL при этом не скачивается:

```powershell
tg-recall config set transcription.backend whisper-cli
```

## Проверка одного сообщения с источником

Сначала запустите диагностику. `doctor` показывает безопасный статус готовности:
выбранный движок, имя исполняемого файла и результат его поиска, настроенную
модель, наличие локальной модели и корректность параметров. Полный путь на
компьютере, текст транскрипта, учётные данные и материал сессии не выводятся.

```powershell
tg-recall --json doctor
```

Затем расшифруйте ровно одно архивное медиа по его `tg://` ссылке на источник.
Ссылка уже должна указывать на медиа в архиве; при необходимости сначала
поставьте его в очередь через `sync --media voice,audio` и скачайте через
`media download`.

```powershell
tg-recall --json transcribe run --provider local --citation tg://chat/-1001234567890/message/42 --limit 1
```

Транскрипт сохраняется локально и становится доступен для поиска по словам
вместе со своей ссылкой на источник. Если локальный процесс завершился ошибкой,
задание остаётся доступным для повтора; исправьте конфигурацию или локальную
установку, снова проверьте `doctor`, затем повторите то же сообщение.

AI-агент может запросить транскрипцию только для одной явной разрешённой
`tg://` ссылки на источник. Он не может менять настройки транскрипции,
запускать обработку всех ожидающих заданий без ограничения, скачивать модели
или передавать произвольные аргументы.
